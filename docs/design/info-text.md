# Info icon wording: draft for the owner's markup

Status: approved and built. Table 1 on 2026-11-05; Tables 2 and 3 on 2026-11-08, after the owner chose option B on 2026-11-06 (one
icon per group of settings, and single controls keep a tooltip). The 3.11 review's rewording (findings M2 to M6 and M9) was
approved on 2026-11-09 and is in the tables below. In the popups, each `<br>` below starts a new line. A test
(`InfoIconTests`) checks that the screens say these texts word for word, so a change goes here first.

How to read it:

- Every draft was checked by reading the code on branch `sprint/3.11`. The app was not run.
- "Checked against" cites `file:line`. File names are unique under `src/`. `README.md` means the one at the repository root and
  `USER-GUIDE.md` the one in `docs/`.
- Line numbers are from the working tree on 2026-11-05. Other sprint work was changing the tree while this was written, so a
  line may have moved by the time you read it.
- Each icon is read on its own, so a text explains a word such as root or retained itself, even when another row already did.
